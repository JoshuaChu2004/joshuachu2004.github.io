# Races

Custom player races and racial variants for D&D 5e.

## Creating New Races

To add a new race:

1. Create a markdown file in the races collection directory:
   - `dnd/_races/racename.md`
2. The page will automatically be accessible at `/dnd/races/racename/`
3. Update this overview page with a link to your new race

## Race Design Guidelines

When creating new races:

- Follow D&D 5e racial trait structure
- Balance ability score increases appropriately
- Include unique racial features
- Consider cultural and biological aspects
- Provide interesting roleplay opportunities
